## 目标

把 `window-controller` channel 的**本地子集**（8 个成员）迁到 Rust Host。这是当前唯一「已被 Rust Host 服务、但整条 channel 缺失」的活链路：dev 开关下手机远控的共享 Host attachment 已连 Rust Host（`packages/desktop/src/main/index.ts:849-864` → `webRemoteControlSharedHostAttachments.ts:136-153`），而桌面/手机的**时间线、置顶、归档、全局搜索、命令中心**全部走它（`useGlobalTaskList` 用 base services，11 处调用点 / 8 个文件），现在返回 NotImplemented → 列表为空。

## 已验证的关键事实

- **TS 真相源**：投影是纯函数可做 oracle —— `packages/desktop/src/host/windowHostControllerProjection.ts`（556 行，rows/logEpoch/seq/快照/增量已在源码中读全）；服务层 `windowHostControllerService.ts`（801 行），overlay 映射 `sessionOverlay`（:78-125），membership 三读（:345-389），刷新 single-flight + 世代守卫（:391-434）。
- **无运行时段工作**：`controller/*` topic 是 Host 侧投影；运行时只需继续供 sessions-index，而 `TaskIndexSyncer` 已在消费（`task_index_syncer.rs`，`Core.summaries` 就是 overlay 数据源）。
- **Rust 可复用**：`list_task_metas`（`tasks_index/mod.rs:216`，支持 pinned/archived 过滤且排序与 TS 同）、`domains_task_query`/`domains_task_state`/`domains_task_delete`、`WorkspaceEvents` 总线、`Channel::with_scoped`+`with_open`/`with_close`（同 `agent_v4` 形状）、`collation.rs`（`localeCompare` 等价）、`inventory_ts.rs:56` 已含 8 成员（当前 Pending）。

## 设计（状态所有者与数据流）

```
tasks-index（SQLite 单写者）──┐
                              ├─→ 投影 rows（meta + membership + liveStatus/activity）
sessions-index 摘要 ──────────┘        ▲            │
（syncer Core.summaries）              │ 变更信号    ├─→ topic 快照/增量帧（logEpoch/seq）
                                       │             └─→ 每连接订阅 → EventFire
 信号①WorkspaceEvents.task_list_changed（索引写后，已有）
 信号②syncer overlay 变化   ③controller mutation 完成
```

- 投影（新模块）是 rows/topic 水位/subscribers 的**唯一所有者**；索引仍是唯一写者，投影只读+订阅。
- 刷新语义逐条对齐 TS：lazy（订阅不刷新）、single-flight + 世代守卫（用串行队列+世代号，不用超时）、失败保留上次可信快照。
- 帧面照抄：`{topic, subscriptionId, logEpoch, fromSeq, toSeq, sentAt, payload}`；快照 `fromSeq:0`；每批增量 `seq+=1`；`allRows()` 排序 `updatedAt desc` + `taskKey localeCompare`（走 `collation.rs`）。

## 验收与门禁

- 对照 TS 优先：帧序列 L4（`subscriptionId`/`logEpoch`/`sentAt` 归一并登记）+ list/mutation 与真实 TS 服务 `toEqual`；端到端用真 WebSocket + embedded 实例；负向验证（改坏 membership 分类 / seq gap / 搜索叠加，各自必须失败）。
- 门禁三连：`cargo fmt --all` + `cargo test --workspace` + `cargo clippy -D warnings`（apps/escode-host）→ `pnpm check:escode-host` → 相关 vitest；提交按**显式路径**（共享工作树，禁止 `git add -A`）。

## 登记差异（写进 spec）

1. **远程 source 不支持**（无远程注册表）：remote identity scope 不贡献行（TS 在无在线远程会话时也为空）；`remoteSessionId` 字段不下发。移除条件：remote 域（优先序 9）。
2. **作用域**：TS 按窗口/attachment，Rust 按 RPC 连接（多窗口对同一 Host 时可见）。
3. **刷新触发点**：Rust 由索引写事件 + syncer overlay 驱动；逐条比对 TS 的 task-service 事件触发，不可达处登记。
4. `connectionState` 本地 `connecting`→`online`；5. `subscriberScope` 不转发（沿用 agent-v4 既有登记）。

## 不做（登记为缺口）

远程 source 路由、escode-task 分组写面（`createTaskGroup` 等）、escode-task 写面九法、桌面窗口自身 host 进程无关化（`desktopHostProcess.ts:762`，需 realtime/broadcast/cron 控制协议，独立工作包）。
